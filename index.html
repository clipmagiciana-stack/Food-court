Google Sheet Backend

Sync & manage dishes live from Google Sheets!

💡 How to Connect Your Google Sheet:

Option A: Publish to Web (Fastest CSV)
1. Copy headers & data from google_sheet_template.csv into Google Sheets.
2. Go to File ➔ Share ➔ Publish to Web.
3. Select Entire Document as CSV, click Publish.
4. Copy the link and paste above!

Option B: Google Apps Script Web App
1. Open Google Sheet ➔ Extensions ➔ Apps Script.
2. Paste contents of google_apps_script.js and click Deploy ➔ New Deployment ➔ Web App.
3. Set Who has access to Anyone, click Deploy and paste link above!

🏷️ Categories Support:
Any category specified in your sheet (e.g. starters, main, desserts, drinks, specials, breakfast) will automatically create a tab on the menu!
